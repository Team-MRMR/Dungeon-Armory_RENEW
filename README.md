# V0.4.1-CPP
서브로 개발하는 브랜치입니다.
주로 이윤석이 작업하며, 이 부분에서는 C++ 위주의 개발이 이루어집니다.    

# 브랜치간 협업 방식
기본적으로 CPP 브랜치에서 코드로 개발한 부분을 Alpha 브랜치로 PR합니다.    
Alpha에서는 PR에서 받은 CPP를 바탕으로 **프로젝트 빌드 후** 개발이 가능합니다.    
또한 Alpha 브랜치에서 작업한 내용이 있을 경우, CPP 브랜치의 업데이트를 위해서 PR을 주셔야 합니다.

즉, Alpha와 CPP 브랜치는 작업하는 브랜치만 다를 뿐이며 작업 충돌 사항을 최소화하고자 해당 다른 브랜치에서의 작업을 도입한 것입니다.    
**각자의 브랜치에서 Commit과 Push 이후에는 반드시 다른 브랜치에 Pull Request를 하여 작업 환경의 업데이트를 유지**해야 합니다.
